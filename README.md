# 🎨 ReSergeDX's Art Portfolio - SCCS Project

## 📖 Description
Art portfolio website for the ResergeDX account. It showcases the artist's work and is organized into three pages: a home page with the gallery, an "About" page, and a "Commissions" page for people interested in requesting custom artwork. It is a static site built with HTML and SCSS/CSS, with no frameworks or build tools required.

## 🛠️ Technologies used
- **Main language:** HTML5
- **Styling:** SCSS / CSS
- **Frameworks:** None
- **Database:** None
- **Tools:** Any static file server or a plain web browser

## 📂 Project structure
- `index.html` — Home page
- `about.html` — About the artist
- `comisions.html` — Commissions information
- `img/` — Artwork and image assets
- `scss/` — Stylesheets

## 🚀 Getting started

### Prerequisites
- A modern web browser
- (Optional) A local static server such as the VS Code *Live Server* extension

### Installation
```bash
git clone https://github.com/ResergeDXVS/ResergeDX_art_portafolio.git
cd ResergeDX_art_portafolio
```

### Run
Open `index.html` directly in your browser, or serve the folder with a local server:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).
